# kaiwu-MathorCupA 🧮

> 🏆 **2026 MathorCup 数学建模竞赛 A 题 · 校内评比一等奖（校内唯一）**  
> 个人职责：程序设计、QUBO 数学模型构建与全套求解代码实现

本项目基于**腾讯开物（Kaiwu SDK）量子退火 / 组合优化计算架构**，针对 MathorCup A 题中复杂的车辆路径规划与调度组合优化问题，设计了 QUBO（二次无约束二值优化）建模与混合优化求解方案。

---

## 📌 问题定义与核心思路

赛题要求在特定配送网络中规划最优路线与发车调度策略，核心挑战在于随着配送点与车辆规模增加，传统经典算法面临严重的组合爆炸问题。

本项目将车辆路径规划问题（VRP/CVRP/VRPTW）转化为 **Ising / QUBO 能量泛函**，利用量子退火原理在全局超高维解空间中跳出局部极小值：

* **目标函数**：最小化总行驶距离、车辆启用固定成本与时间窗违约惩罚；
* **约束构建**：每个配送点仅被访问一次（一笔画回路）、载重约束与时间窗紧致性约束，通过 Lagrange 乘子项构建为二次罚项；
* **两阶段混合求解**：大规模场景下采用“**空间聚类分区 + 量子退火精确路由**”策略（K-Means/层次聚类预分组，结合 Kaiwu 量子退火器在各子簇内快速搜索全局最优 Hamiltonian 回路）。

## 🏗️ 逐问求解体系

| 模块文件 | 对应问题 | 算法与建模重点 | 输出成果 |
| :--- | :--- | :--- | :--- |
| **`q1.py`** | 问题一：基础路径规划 | 经典 TSP 问题的 QUBO 矩阵映射与开物模拟退火求解 | 单车基准最优回路 |
| **`q2.py`** | 问题二：容量受限车辆路径 (CVRP) | 载重约束与多车派送协同，车辆负载平衡约束惩罚化 | 多车任务划分与路径组合 |
| **`q3.py`** | 问题三：带时间窗路径规划 (VRPTW) | 引入软/硬时间窗到达惩罚项，动态时序路径展开 | 满足交货时效的全局调度 |
| **`q4.py`** | 问题四：多目标动态鲁棒优化 | 车辆数、里程与违约风险的多目标 Pareto 前沿搜索 | 综合成本最优调度方案 |
| **`main.py`** | 综合执行主入口 | 数据预处理、特征归一化、各问参数调度与批量执行 | 全量方案计算总成 |
